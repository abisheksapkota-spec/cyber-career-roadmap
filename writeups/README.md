# Writeups

One file per room, machine or CTF challenge, named like `tryhackme-pre-security.md`.

## Writeup template

```
# Room / challenge name
Platform: TryHackMe / HackTheBox / picoCTF
Date:
Difficulty:

## Goal
## Steps I took
## What I learned
## Commands and tools used
```

Do not publish flags or answers for active competitions. Describe your method and what you learned instead.
