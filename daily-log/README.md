# Daily log

One file per day, named `YYYY-MM-DD.md` (for example `2026-10-09.md`). Copy `TEMPLATE.md`, or use the dashboard's **Create today's log on GitHub** button, which opens a prefilled new file.

Every file here counts as one day on your streak. The GitHub Action reads these filenames and updates the streak in the main README.

Tip: keep it short. Three bullet points is a valid log.
