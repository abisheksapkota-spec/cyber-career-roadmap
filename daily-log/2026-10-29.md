# 2026-10-29: Networking Core Protocols (TryHackMe) ✅

## Ports
- TELNET 23 | DNS 53 | HTTP 80 | HTTPS 443
- FTP 21 | SMTP 25 | POP3 110 | IMAP 143

## Commands
- `whois domain | grep -i "creation date"`: domain age
- HTTP over telnet: `GET / HTTP/1.1` + `Host:` + blank line
- FTP: `ls`, `get file`, `quit`
- POP3: `USER`, `PASS`, `STAT`, `LIST`, `RETR n`, `QUIT`
- IMAP: `LOGIN`, `SELECT`, `FETCH`, `LOGOUT`
- SMTP: `DATA` starts the body, a lone `.` ends it

## Notes
- Plaintext protocols expose credentials; use encrypted versions in real life.
- The blank line ends the HTTP headers.
